# Menu, profile, mod loader, settings, keybinds

- **Main menu** `export/web/home.{html,css,js}` is served at `/` via `KINO_HOME=home.html` (env var read by `.tools/serve.mjs`, set in the quadlet). Kino itself is `/index.html`. Tabs: Play (map browser from `mods/maps.json`), Loadout (weapon thumbnails rendered from world models, stats, bonuses), Character (3D preview), Mods. `maps.html` just redirects to `./#play`.
- **Profile** `profile.js`: shared localStorage profile (`kino.mods.progression`: xp, level, loadout, character, stats), plus unlock rules read from `mods/progression/progression.json`. The menu and the progression mod both use it.
- **Mod loader** `mod-loader.js`: `ModHost` merges data patches (objects merge, arrays replace, `null` deletes, `{add,remove}`, weapon `"extends"` which also sets `baseId`), calls an optional `prepare(data)` from scripts, wraps session/enemies methods to emit events, then runs `setup(api)`. `host.camera` and `host.hideViewmodel` let a mod take over rendering.
- **Settings**: `settings.js` (localStorage `kino.settings`: sensitivity, ADS sensitivity, invert Y, FOV, volume, render scale, FPS counter; `renderSettings()` builds the form). `game-menu.js` + `game-menu.css` add Settings and Main menu buttons plus a settings overlay to any game page's `#menu`, and apply volume, render scale and FPS; sensitivity and FOV are read directly in the loops. The main menu has a Settings tab.
- **Dev settings**: `FIELDS` entries with `group:'dev'` render inside a collapsed `<details class="settings-dev">`. `devConsole` (default off) gates the cheat console's ` key; the pause-menu CONSOLE button was removed.
- **Keybinds**: `settings.binds` holds only the changed keys; `ACTIONS`/`DEFAULT_BINDS` are in settings.js. game-menu.js remaps in the capture phase: a rebound key is re-dispatched as the action's default `code`, and a default key whose action moved elsewhere is swallowed. The game loops are untouched.
- **Loadout picker** (2026-10-01, BO7-style): weapon slots show class tabs (`CLASSES` in home.js: Assault Rifles, SMGs, Shotguns, LMGs, Snipers, Pistols, Launchers, Specials, mapped from `weaponClass()`), each with `unlocked/total`. The grid shows one class, opening on the class of the gun in the slot (remembered per slot in `activeClass`). Cards are bigger, with badges for weapon level (`LV n` / `MAX`) and camos unlocked (`CAMO n/6`).
