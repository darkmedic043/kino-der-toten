# Props

## Terminal booth (`mods/terminal-booth`)

A payphone-style wall booth whose "phone" is a CRT terminal with a retro keyboard (coiled cord), plus a handset on a hook, corrugated hoses, back-wall conduits with sagging cable runs, glass coolant tubes, a junction box and live wiring. The user wants it on several maps; Kino is the first.

- **Model**: generated entirely by `.tools/build-terminal-booth.py` in Blender 5.2.2. Blender is a portable install at `~/.local/opt/blender` (symlinked to `~/.local/bin/blender`, no sudo). Rebuild: `blender -b -P .tools/build-terminal-booth.py -- export/web/mods/terminal-booth/terminal_booth.glb [--nobake] [--render <dir>]` (about 1.5 min with the bake on the GTX 1660 Ti via CUDA; `--render` writes Cycles preview PNGs). Units are inches. The back is at local z=0, and the booth faces local +Z. It is 44 wide, 30 deep with the keyboard ledge, and 98 tall (the conduits reach 132).
- **Texturing**: procedural Cycles materials (`grimy()`: edge wear from bevel-normal vs normal, AO crevice dirt, floor-height dirt, rust streaks, hazard stripes) are baked into one 2048² set on the joined opaque mesh: base colour, ORM (AO/rough/metal) and a tangent normal map (bevel-node rounded edges). WebP inside the GLB, about 6.6 MB, stored in LFS. Gotchas: the DIFFUSE colour bake returns black for metallic surfaces, so the metallic links are cut before that bake and restored after. Plastics use `bare_metal=False`, so worn edges don't turn metallic. `glTF Material Output` node group feeds occlusion.
- **Separate live meshes** (not baked, found by node name): `crt_screen` and `sign_glow` (quads with 0..1 UVs; use a canvas with `flipY=false`), `wire_*` (sweeps with u = arc length × 0.01), `led_*`, `coolant_*` (v along height), `glass_*`, `spark_*` empties at the severed wire ends.
- **Mod**: `placements.json` lists spots per map id (`kino` for Kino, otherwise `api.map.id`) as `{position, yaw}`, plus the sign text. Each spot is snapped to the floor and flush to the nearest wall behind it (collision rays). It adds a 44×100×30 box to `world.dynamic` (`window:true`). The screen is a 512×384 canvas redrawn at 15 Hz: boot lines, then idle status lines; "NO MAINS POWER / STANDBY" until `session.power`. The sign is a canvas that occasionally flickers. Live wires have a pulse texture scrolling along u, and the severed ones spark (additive points plus a flash plus a WebAudio crackle into `audio.master`). LEDs blink per kind, coolant scrolls, and an additive floor glow sits in front. `window.kino.terminalBooth.booths[i].print(line)` / `.setSign(text)` are hooks for the user's later use. It runs before `map-materials` in mods.json, so its shaders are compiled during loading.
- **Kino spot**: the spawn room's west wall pilaster, `[-388, 82, 1338]` yaw 90. Its sconce is at y 238, above the conduits, and it sits between the wall-buy (z 1265) and the barricade window (z 1380–1420). The north wall was rejected because the hanging lamps at (±96, 166, 1492) are at roof height.
- **Not done**: zombies aren't blocked by it (the navmesh is baked), and there's no interaction yet. Animations run on the `update` event, which only fires while a game is live; headless shots need `kino.debug.resume(); kino.debug.step(n)`.
