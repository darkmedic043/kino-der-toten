# Props

## Terminal booth (`mods/terminal-booth`)

A payphone-style wall booth whose "phone" is a CRT terminal with a retro keyboard (coiled cord), plus a handset on a hook, corrugated hoses, back-wall conduits with sagging cable runs, glass coolant tubes, a junction box and live wiring. The user wants it on several maps; Kino is the first.

- **Model**: generated entirely by `.tools/build-terminal-booth.py` in Blender 5.2.2. Blender is a portable install at `~/.local/opt/blender` (symlinked to `~/.local/bin/blender`, no sudo). Rebuild: `blender -b -P .tools/build-terminal-booth.py -- export/web/mods/terminal-booth/terminal_booth.glb [--nobake] [--render <dir>]` (about 1.5 min with the bake on the GTX 1660 Ti via CUDA; `--render` writes Cycles preview PNGs). Units are inches. The back is at local z=0, and the booth faces local +Z. It is 44 wide, 30 deep with the keyboard ledge, and 98 tall (the conduits reach 132).
- **Texturing**: procedural Cycles materials (`grimy()`: edge wear from bevel-normal vs normal, AO crevice dirt, floor-height dirt, rust streaks, hazard stripes) are baked into one 2048² set on the joined opaque mesh: base colour, ORM (AO/rough/metal) and a tangent normal map (bevel-node rounded edges). WebP inside the GLB, about 6.6 MB, stored in LFS. Gotchas: the DIFFUSE colour bake returns black for metallic surfaces, so the metallic links are cut before that bake and restored after. Plastics use `bare_metal=False`, so worn edges don't turn metallic. `glTF Material Output` node group feeds occlusion.
- **Separate live meshes** (not baked, found by node name): `crt_screen` and `sign_glow` (quads with 0..1 UVs; use a canvas with `flipY=false`), `wire_*` (sweeps with u = arc length × 0.01), `led_*`, `coolant_*` (v along height), `glass_*`, `spark_*` empties at the severed wire ends.
- **Mod**: `placements.json` lists spots per map id (`kino` for Kino, otherwise `api.map.id`) as `{position, yaw, model?, scale?}`, plus the sign text. Each spot is snapped to the floor and flush to the nearest wall behind it (collision rays). It adds a 44×100×30 box to `world.dynamic` (`window:true`). The screen is a 512×384 canvas redrawn at 15 Hz: boot lines, then idle status lines; "NO MAINS POWER / STANDBY" until `session.power`. The sign is a canvas that occasionally flickers. Live wires have a pulse texture scrolling along u, and the severed ones spark (additive points plus a flash plus a WebAudio crackle into `audio.master`). LEDs blink per kind, coolant scrolls, and an additive floor glow sits in front. `window.kino.terminalBooth.booths[i].print(line)` / `.setSign(text)` are hooks for the user's later use. It runs before `map-materials` in mods.json, so its shaders are compiled during loading.
- **Kino spot** (moved there at the user's request): the lobby wall under the west staircase, next to the arch passage (collision wall x −208 for z 850–910; the *visible* wall is at x −200, 8 in front, so `snap` also raycasts the rendered meshes and takes the nearer hit). The stair stringer is about 87 above the floor, so this spot uses `terminal_booth_compact.glb` (`--compact`: no conduit risers or cable spans above the roof, and the vent moved forward) at `scale: 0.9`. The first spot was the spawn room's west wall pilaster `[-388, 82, 1338]` yaw 90.
- **Interior light**: a `led_strip` emissive bar under the roof plus a real `PointLight` (#f2f6ff, `lightIntensity` 700 in placements.json, range 78×scale, decay 2, no shadow). It's added during loading and never toggled; only its intensity jitters.
- **Zombie pathing**: the navmesh is baked without the booth, and disabling polys (the door mechanism in `setDoors`) is too coarse for big lobby polys. So the mod wraps `world.path` (path segments crossing the footprint, which is 22·s+16 wide each side and 30·s+16 deep, get detours at its front corners) and `world.closest` (snaps inside the footprint are pushed out). Checked: a path along the wall from z 820 to 945 bends out to the corners at x −161.
- **Not done**: no interaction yet. Animations run on the `update` event, which only fires while a game is live; headless shots need `kino.debug.resume(); kino.debug.step(n)`.
