# Journal (`mods/journal`, JOURNAL.EXE, 2026-10-17)

User: an app that keeps track of every map's Easter eggs; doing a step unlocks that step's instructions in the journal for good; selecting a quest drops map markers to guide you through it, so players don't need tutorials every time.

- **Quest book** `mods/journal/quests.js` (`JOURNAL`): per map (`der-eisendrache`, `moon`, `kino`, `cheese-cube`, `the-giant`) its quests, each `{id, name, kind, steps:[{title, how, where?(L), done?(L)}], progress?(L)}`. Linear quests give `progress(L)` (steps done so far, read from the map's own state); the others give `done(L)` per step (parts found in any order). `where(L)` returns world positions for the markers. Static text is shown on any map; the functions run only on the quest's map.
- **Live context** `L` (mod.js): `prompts(re)` (positions of the map's interactions currently shown whose prompt text matches: follows quest items wherever they are), `nodes(re, keep?)` (visible builder nodes), `ents(name)` (BO1 entities), `targets(kind)` (Moon's MoonFeatures targets), `castle` (`kino.castle`), `de` (quest spots exported by der-eisendrache `ee.js`, `side.js`, `side2.js`: `SUMMON`, `TRAVEL`, `PAD`, `SPOT`, `STONES`, `PADS`, `RUNS`, side `SPOT` as `SIDE`, side2 `SPOT` as `SPOT2`, `GRAMOPHONES`, `CLAWS`, `SKULLS`), `cc()`/`ccSuits()` (Cheese Cube), `tile(id)` (a scoreboard collectible: `kino.scoreboard.get`, added for The Giant), `reels()`/`meteors()` (Kino's `kino.debug.completionState`/`specialState`).
- **Coverage**: Der Eisendrache: main egg (9 steps, ee.js state.step), the four bow quests (start, arrow, their steps from `bows.sites`, place, souls, take), Wrath of the Ancients, Pack-a-Punch, Ragnarok and Rocket Shield buildables, and the side eggs (plates, clock tower and plunger, plant, Disco Inferno, Requiem, Dead Again, In Plain Sight skulls, claw hat). Moon: Big Bang Theory (one step per moon-progression stage), music egg. Kino: film reels (link, room outside time, reel, projector, all three), 115 meteors. Cheese Cube: power switch, Cheese Brothers, trivia (answers per question), dial puzzle and ending, Iron Man armor. The Giant: Fly Trap, the song.
- **Recording**: every 0.5 s in a live game the current map's steps are checked; a step done for the first time is saved in `kino.mods.journal` `{maps:{[map]:{[quest]:[step indices]}}}` (cloud-synced: cloud.js TRACKED) with a toast. Steps before a linear quest's progress count as done. Co-op: the quests are the team's, so team progress records. Cheat games record nothing.
- **Tracking**: `kino.journal.track(map, quest)` (local only, `kino.journal.track` in localStorage). On that map a panel (`#journal-track`, right, under the top) shows the current step (the first not done this match): title and instructions if recorded, otherwise "Not recorded yet". Markers (`#journal-marks`, diamonds with the distance in m, yellow and pinned to the edge when off screen) show the current step's `where` points, **only for recorded steps** (my reading of "perma unlock": the first time through you find it yourself). Positions are refreshed twice a second, projected every frame.
- **JOURNAL.EXE** (desktop.js; icon at the top of the right column): map tabs (◆ = the map you're on), the map's quests with recorded counts and TRACKING, and the selected quest's steps (recorded: title and instructions; unrecorded: "??? · NOT YET RECORDED"; "DONE THIS MATCH" on the map you're on). TRACK QUEST / STOP TRACKING on the current map only.
- Adding a map's quests: add an entry to `JOURNAL` and, if it needs live data, a field on `L` in mod.js. Prefer `prompts()` and `nodes()` for markers so positions follow the quest's own interactions and props.
