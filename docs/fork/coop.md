# Co-op multiplayer

- **Co-op** (`mods/multiplayer`, `net.js`, server rooms): the server has a dependency-free RFC6455 WebSocket at `/api/ws` (upgrade handler, masked client frames, 25 s pings) and rooms of 4-letter codes, max 4, where the creator is host and the room closes when the host leaves; `GET /api/rooms/<code>` returns `{page, map, players}` for join-by-code. Relay protocol: `{t:'to',target:'host'|'all'|id,data}` becomes `{t:'msg',from,data}`. Game protocol: `pose` (all, 15 Hz), `snap` (host, 12 Hz: round, phase, doors, power, boards, zombies `[id,kind,x,y,z,yaw,state,hp,speed]`, and a `gid` that changes on host reset), `dmg` (client→host) answered by `res` (points/XP applied on the client), `hit` (host→victim), `world` (client doors/power), `ended`. The host sets `enemies.targetFor` (nearest player, sticky ×1.3) and wraps `enemies.onDamage(amount,z,victim)`; the `enemies.js` upstream edit adds the `targetFor` hook plus `victim` args. Clients replace `enemies.update`/`hurt`/`nuke` with a mirror. `host.remoteDamage` suppresses host XP and hitmarkers for teammates' hits (`kill` event `remote` flag). URL: `?mp=host` creates, `?room=CODE` joins (history rewrites to `?room=`). Stage 3: power-ups are host-authoritative (host ids `nid`, the snap `pu` list, `pu` collect broadcast calls `kino.debug.collectPowerup` everywhere, and the host also grabs for remotes within 70); the box location is in the snap `box` (client teddy moves are sent as `box`); custom-trap activations are broadcast as `trap`; Kino trap kills already propagate through `dmg`. Stage 4: in co-op, a lethal hit without QR is intercepted (`session.damage` wrapper) and becomes DOWN (phase `reviving`, reviveLeft ∞, perks cleared, 30 s bleed-out, camera lowered and rolled); teammates hold F (tracked via KeyF/KeyE) within 90 for 3 s and send `revive`; bled-out players are DEAD and spectate via `host.camera`, respawning on `roundEnd`; everyone down gives the host `gameover` broadcast and `forceGameOver()`. The snap phase maps the host's personal `reviving` to `fighting`. Host migration: the server reassigns the host on leave (`left` carries `host`) and the new host calls `becomeHost(true)` (restores the original enemies/powerups functions; mirrored zombies keep their host ids because clients set `z.id=netId`). A Worker-driven 20 Hz ticker keeps the host simulating while paused or hidden. The HUD label switches from SOLO to CO-OP.
- **Co-op lobby** (multiplayer mod): the #start click is blocked (capture phase) until `lobby.go`. Players send `{t:'ready'}` to the host once `getState().ready`; the host keeps the set and broadcasts `{t:'lobby',ready,started}`. The host's START GAME is enabled when every player in `net.players` is ready and starts everyone; others then get "click to join in" (pointer lock needs a click), and late joiners go straight in once ready. Verified with two browsers.
